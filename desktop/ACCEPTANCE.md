# 0.2.0 实机验收

1. 完全退出旧版（含托盘）后安装 0.2.0。系统设置应显示 0.2.0。
2. 新增 WhatsApp 会话：中央应显示 web.whatsapp.com 的官方页面，而非“官方二维码区域”占位图；手机关联设备扫码。
3. 新增第二会话：应显示独立登录页面，不自动登录第一账号。扫码不同账号并来回切换，确认各自聊天独立。
4. 完全退出应用，再启动：检查仍可恢复登录。若手机端撤销关联，应由官方页面重新要求扫码。
5. 切换平台创建 Facebook 会话：显示 business.facebook.com 页面，完成官方登录；另建账号检查隔离。
6. 打开系统设置/环境配置/账号菜单：页面应让开浮窗；关闭后恢复原页面且不重新登录。
7. 休眠停止对应页面，唤醒恢复同一持久会话；刷新仅刷新选定账号；删除会话不清理登录数据。
8. 网络断开应显示加载错误并可重试；已开启但未实现的代理不得回退直连。
9. 使用自己的测试联系人，通过官方页面手动收发文本和附件。不要将高级工具尚未接入提示视为已完成业务功能。

当前账号卡片显示本地环境名称和页面加载状态，不将“页面加载成功”当作“已登录”。麦克风、摄像头等权限暂未开放。自动群发、翻译等需独立开发并验收。
