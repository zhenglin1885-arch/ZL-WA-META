## 0.2.0-R6

- 修正状态点 CSS：已登录绿色，加载异常/离线黄色，未登录红色，休眠灰色。
- 窗口移动/缩放不再清空原生页面布局；账号菜单限制在左侧栏内，不再隐藏整个 WhatsApp 页面。
- 顶部接入公网 IP 检测、HTTP 往返耗时、30 秒更新、手动刷新和复制。耗时目标是 IP 查询服务，并非 ICMP Ping。
- 头像补充自身资料的 previewEurl/eurl、自身 LID 及自身头像控件来源；保留失败诊断，尚待 Windows 账号实测确认。
- 接入原生消息/掉线/转发完成通知；系统设置可主动发送通知。注册 Windows AppUserModelID 与开始菜单快捷方式属性。
- 安装完成页默认启动应用；安装和卸载先请求正在运行的应用退出，仍被占用时中止并提示，而不是删除一部分后假报成功。升级旧版需先退出旧程序。
- 接入真实聊天列表、文本/图片/图文/视频/文件/名片提交及逐对象记录。文件上限 25 MB，失败不自动重试；提交不等同于送达。
- 群组开闭状态来自真实群资料，每次更改再次验证管理员身份；权限不足返回失败。
- 翻译接入 Google Cloud、DeepL、OpenAI、Gemini 官方 HTTP 服务。本机加密保存 API Key。发送先翻译回填、再次确认才发送；接收在已加载的文本消息下显示译文。需要用户自己的有效服务权限，当前账号发送/接收共用所选服务。

验证边界：自动检查通过不代表 Windows 原生窗口、WhatsApp 动态页面、第三方翻译账号、通知中心和卸载流程已完成实机验收。没有在开发环境向真实联系人发送消息或修改真实群权限。代理、联系人备注注入、无限置顶、自动更新等原有未接入项不在本次完成范围内。
